## 🐔 Chicken Shooter

### Context  
Built as a collaborative project with my 9-year-old daughter, combining learning, creativity, and hands-on product experimentation using modern development tools.

### Problem  
Learning programming can be abstract and disengaging for kids without immediate feedback or ownership.  
Additionally, experimenting with new tools is often disconnected from real user interaction.

### Solution  
Designed and developed a simple interactive game ("Chicken Shooter") that allowed for:
- Immediate visual feedback  
- Iterative feature development  
- Joint decision-making on gameplay and UX  

The project served both as a **learning platform** and a **sandbox for rapid experimentation with new tools**.

![Chicken Shooter Screenshot](https://raw.githubusercontent.com/amir-kedem/Gonni_Game/main/Screenshot.png)

### Key Features  
- Real-time interaction and feedback  
- Simple game mechanics designed for quick iteration  
- Progressive feature addition based on user (child) feedback  
- Lightweight architecture enabling fast experimentation  

### Product Thinking  
- Treated my daughter as the **primary user and stakeholder**  
- Prioritized **engagement and fun over technical complexity**  
- Iterated based on real usage (“what’s fun” vs. “what’s correct”)  
- Used the project to validate how quickly new tools can translate into usable experiences  

### Impact / Outcome  
- Increased engagement and ownership in the learning process  
- Demonstrated ability to:
  - Build fast MVPs  
  - Validate ideas with real users  
  - Iterate based on feedback  
- Provided a hands-on environment to explore and evaluate new development tools
