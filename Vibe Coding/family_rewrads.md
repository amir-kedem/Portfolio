## 🎯 Family Rewards

### Problem  
Families struggle to consistently enforce responsibilities and routines.  
Existing solutions are either too complex, not engaging for children, or fail to create sustained motivation.

### Solution  
Designed and built a lightweight gamified system that translates daily responsibilities into a structured reward mechanism.  
The system focuses on simplicity, visibility, and behavioral reinforcement.

![Family Rewards Screenshot](https://raw.githubusercontent.com/amir-kedem/family_rewards/main/assets/Screenshot.png)

### Key Features  
- Task assignment and tracking  
- Points-based reward system  
- Clear feedback loop for completed actions  
- Simple UX tailored for daily usage  

### Product Thinking  
- Focus on **behavioral design** rather than feature complexity  
- Reduce friction to near-zero for repeated daily actions  
- Emphasize **consistency over intensity** (small daily wins)  
- Built as an iterative product experiment  

### Impact / Outcome  
- Demonstrates ability to take a real-world problem → define solution → build MVP  
- Showcases product thinking in behavioral systems and engagement loops  
- Serves as a foundation for future extensions (analytics, personalization, automation)
